# YoYoJoy Day — исторический технический обзор

> Источником текущего состояния служит [`PROJECT_MEMORY.md`](../PROJECT_MEMORY.md). Этот документ описывает устройство продукта, но не фиксирует оперативные хвосты, деплои или состояние production-данных.

## Что это

YoYoJoy Day — прогрессивное веб-приложение (PWA), которое не нужно скачивать из магазинов. Пользователь сканирует QR-код на физическом бумажном календаре YoYoJoy → попадает на сайт → регистрируется → добавляет на главный экран. Каждый день приложение показывает персонализированный гороскоп, фразу поддержки и праздник, сгенерированные AI под конкретного пользователя.

## Технический стек

### Фронтенд
- **React 19** + TypeScript + Vite
- **Tailwind CSS** — дизайн-система Zen-Emerald (#006a65, #2FA7A0, #fcf9f4)
- **Framer Motion** — анимации и переходы
- **Zustand** — глобальное состояние с localStorage persistence
- **Vite PWA Plugin** — Service Worker, manifest, offline support
- **Web Push API (VAPID)** — push-уведомления без Firebase
- Размер бандла: ~422 KB gzip (react-vendor и motion вынесены в отдельные чанки)

### Бэкенд
- **NestJS 11** + TypeScript
- **Prisma ORM 6** + PostgreSQL 15
- **Redis 7** — AI-кэш (живой ответ 36ч, fallback 300с), pool фраз поддержки
- **Cloudflare Workers AI** (`@cf/openai/gpt-oss-120b`) — OpenAI-compatible REST API + серверная Zod-валидация
- **Resend** — транзакционные письма (OTP-коды)
- **web-push** — VAPID push-уведомления (без Firebase SDK)
- **@nestjs/throttler** — rate limiting
- **@nestjs/schedule** — CRON каждую минуту для push

### Инфраструктура
- **Docker Compose** — контейнеризация бэкенда
- **Nginx** — reverse proxy + статика фронтенда + SSL termination
- **Node 22 Alpine** — образ контейнера

## Архитектура данных (PostgreSQL)

Все таблицы в snake_case, база `yoyojoy_day`:

| Таблица | Назначение |
|---|---|
| `users` | email, name, `email_verified_at`, OTP hash, refresh token hash, OTP rate limit счётчик |
| `profile` | zodiacSign, gender, currentMood, avatarUrl |
| `prefs` | timezone, отдельные время и флаг для гороскопа, поддержки, праздников и персональной заботы |
| `daily_feed` | Связка юзер+дата с гороскопом, поддержкой, праздником |
| `horoscopes` | Сгенерированные гороскопы (main, detailed, advice, moon, aspect) |
| `support_phrases` | Фразы поддержки (text, mood) |
| `holidays` | Праздники дня |
| `bookmarks` | Сохранённые юзером тексты (JSONB snapshot — иммутабельны) |
| `notifications` | История отправленных push-уведомлений |
| `web_push_subscriptions` | VAPID endpoint + ключи, по одной на каждое устройство юзера |
| `mood_logs` | История смены настроения |

## Реализованные функции

### Авторизация
- Регистрация через email + OTP (без паролей)
- Вход в существующий аккаунт через email + OTP
- JWT: access token 15 минут + refresh token 30 дней, автоматическая ротация
- Auto-refresh interceptor (single-flight, не дублирует запросы)
- Защита от перебора OTP: 5 неверных попыток за 15 минут → 429
- Незавершённый email можно повторно зарегистрировать и получить новый OTP; только подтверждённый аккаунт получает понятную ошибку и кнопку входа с переносом email
- При высоте Android-экрана до 700px регистрация использует компактные отступы: CTA и вход помещаются на `360×640`; при открытой клавиатуре форма остаётся вертикально прокручиваемой
- OTP-контекст хранится локально 30 минут: если Android/Yandex Browser выгрузил вкладку во время перехода в почту, экран восстанавливает email и правильную ветку регистрации/входа; после успешного OTP контекст удаляется
- Material Symbols загружается локальным сокращённым набором (~23 КБ); при медленной сети названия иконок текстом не отображаются
- Первый экран разделён с auth/app-страницами, нижние секции и фотографии лендинга догружаются лениво; бюджет сборки контролируется `npm run check:performance`
- Смена email с OTP-подтверждением
- OTP письма приходят от day@yoyojoy.online через Resend

### Профиль и настройки
- Имя (необязательно), дата рождения, знак зодиака (авто), пол
- Аватарка — загружается с устройства, сохраняется в БД, синхронизируется между устройствами
- Время push-уведомлений выбирается и хранится как локальное `HH:mm`; сервер сравнивает его с текущим временем в `prefs.timezone`.
- Включение/отключение четырёх типов уведомлений (гороскоп, поддержка, праздники, персональная забота)
- Выход из аккаунта (инвалидирует refresh token на сервере)

### Главный экран
- Ежедневный гороскоп — краткий и подробный вариант
- Фраза поддержки с обращением по имени ("Искандер, сегодня тебе...")
- При смене настроения обновляется ТОЛЬКО фраза поддержки, гороскоп остаётся (экономия токенов)
- 6 настроений с gender-aware метками и иллюстрациями
- Праздник дня
- Кнопка "Другая фраза" — берёт из предзаполненного Redis-пула (без лишних AI-вызовов)
- Блок "Сменить настроение" расположен между Поддержкой и Гороскопом

### AI-генерация
- Провайдер: Cloudflare Workers AI, модель `@cf/openai/gpt-oss-120b`
- Конфигурация: `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`; legacy `OPENAI_BASE_URL` читается только при отсутствии нового URL
- Персонализация: знак зодиака + настроение + пол + имя + дата
- Персональный Redis-кэш 36ч по ключу `pack:short-v2:userId:знак:настроение:YYYY-MM-DD`; имя остаётся только в AI-контексте
- Distributed lock — защита от двойных AI-вызовов при одновременных запросах
- Zod проверяет короткий контракт: «Главное» 2–4 предложения, «Подробнее» 3–4, поддержка 1–2; сломанный или выходящий за границы ответ повторяется один раз
- Содержательный fallback хранится только в Redis 300с, не пишется в PostgreSQL и автоматически заменяется фронтом после повтора
- Пул `support-pool:short-v2:userId:знак:настроение:YYYY-MM-DD`: 5 фраз на 24ч, выдаются без повторного AI-вызова

### Push-уведомления
- Технология: Web Push API + VAPID (без Firebase/FCM SDK)
- CRON каждую минуту сверяет расписание с локальным временем каждого пользователя по `prefs.timezone`.
- Один аккаунт = несколько устройств = получают все одновременно
- Мёртвые подписки (410/404) удаляются автоматически при отправке
- Каждая сработавшая категория отправляется отдельным уведомлением, даже если времена совпадают.
- Каждый календарный праздник приходит отдельным push с полным названием, без счётчика «и ещё N».
- Персональная забота приходит отдельным push по каждой активной и ещё не выполненной сегодня цели; при отсутствии активных целей push не отправляется.
- Веха прогресса приходит отдельным push с явным названием достигшей её цели.
- История уведомлений доступна в приложении
- Очистка истории уведомлений с подтверждением

### Закладки
- Сохранение гороскопа и фразы поддержки
- JSONB snapshot — сохранённый текст никогда не меняется даже при обновлении контента
- Фильтрация по типу

### PWA
- Устанавливается на главный экран без App Store
- iOS: ручная инструкция (Share → На экран Домой)
- Android (Chrome): автоматический баннер установки, показывается 2 раза
- При установке на Android данные сохраняются (токены в localStorage)
- При установке на iPhone нужен повторный вход (Safari изолирует хранилище)
- Offline: Service Worker кэширует ассеты, приложение открывается без сети
- Иконки: YoYoJoy логотип, maskable для Android

### Безопасность
- JWT хранится в localStorage (access + refresh)
- Refresh token хранится в БД как bcrypt-хэш (невозможно использовать утечку)
- OTP хранится в БД как bcrypt-хэш
- CORS whitelist: только yoyojoy.online + *.vercel.app
- Rate limit: register/login 10/15мин, verify-otp 10/час + per-email блокировка
- Helmet + content security policy

### Производительность (оптимизации под слабые Android)
- Убраны все backdrop-blur эффекты (дорогой GPU-эффект)
- welcome-orb: 296 KB JPG → 10 KB WebP (-97%)
- Webpack manualChunks: react-vendor + framer-motion в отдельных чанках
- анимации лендинга работают независимо от системной настройки reduced-motion
- `/api/today` опирается на ISO-ключи DailyFeed/Redis; отдельный HTTP-кэш удалён, чтобы fallback гарантированно заменялся после 300 секунд
- Error Boundary — белый экран при крэше заменён понятным сообщением

### UX-детали
- Таймер до повторной отправки OTP: 2 минуты
- На OTP-странице показывается email на который отправлен код
- Прелоадер не может ждать картинку бесконечно: preload завершается по `load/error` либо по таймауту 4 секунды
- Все CTA-кнопки: solid тёмно-зелёный #006a65
- Landscape-режим: адаптация через Tailwind `landscape:` на всех 11 экранах

## Схема потока пользователя

```
QR-код на календаре
    ↓
yoyojoy.online (Welcome Screen)
    ↓
Регистрация (email + имя) → OTP на почту → Ввод кода
    ↓
Настройка уведомлений (iOS: инструкция, Android: авто-промпт)
    ↓
Настройка профиля (дата рождения → знак зодиака, пол, время push)
    ↓
Прелоадер (AI генерирует первый контент)
    ↓
Главный экран:
  [Картинка настроения]
  [Поддержка на сегодня] + "Другая фраза" + "Сохранить"
  [Сменить настроение]
  [Гороскоп: кратко / подробно] + "Сохранить"
  [Праздник дня]
    ↓
Push-уведомление в выбранное время каждый день
    ↓
Закладки / Настройки / История уведомлений
```

## Известные ограничения

- Уведомление о приходе OTP-письма в Mail.app задерживается на 5-7 минут — это поведение iOS/Android, не нашей системы. Само письмо уходит мгновенно.
- Яндекс Браузер не поддерживает PWA-установку и Web Push — только Chrome/Safari
- На iPhone push работают только из установленного PWA (ограничение Apple)
- AI фразы генерируются на русском — другие языки не поддерживаются
